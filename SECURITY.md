# Security Policy

## Report vulnerabilities privately

Do not disclose vulnerabilities publicly. Do not open a public issue, pull request, discussion, or comment containing vulnerability details.

Use GitHub Private Vulnerability Reporting:

<https://github.com/barbatdev/pi-packages/security/advisories/new>

Include the minimum information needed for assessment, but do not include secrets, credentials, tokens, personal data, local absolute paths, usernames, hostnames, or environment dumps.

If GitHub Private Vulnerability Reporting is temporarily unavailable, retry later. Do not open a public issue or use another public channel for the report.
