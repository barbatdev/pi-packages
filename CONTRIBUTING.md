# Contributing

Contributions may be proposed for this early-stage personal OSS monorepo. [barbatdev](https://github.com/barbatdev), the sole maintainer, triages proposals and retains final discretion over acceptance, prioritization, and maintenance. This is not a support commitment or a roadmap promise.

## Public proposals

- Report reproducible problems with the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md).
- Propose scoped improvements with the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- Keep proposals focused and review the diff before opening a pull request.

## Public-safe evidence

Only publish evidence that is safe for a public repository. Do not include secrets, credentials, tokens, private keys, personal data, local absolute paths, usernames, hostnames, raw logs, session transcripts, environment dumps, private project names, or machine-specific configuration. Use minimal, sanitized reproduction steps instead.

Use public Pi package and extension mechanisms. This repository is independent from Pi and gentle-pi; it is not a fork.

## Security reports

Do not report vulnerabilities or include vulnerability details in public issues, pull requests, or comments. Report vulnerabilities only through [SECURITY.md](SECURITY.md) using private reporting.
